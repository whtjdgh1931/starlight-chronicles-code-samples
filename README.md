# Starlight Chronicles

**조성호 · 1인 개발 · Unity 6000.4.8f1 / C# · Windows**

몬스터를 사냥하고 장비를 강화해 성장한 뒤, 혼자 또는 다른 플레이어와 보스전에 도전하는 2D 액션 RPG입니다.

[Unity 보스 예고 데모](UnityDemo) · [협동 입력 반응](01-coop-input.md) · [보스 투사체 예고](02-boss-telegraph.md) · [전투 결과 저장](03-battle-result-save.md)

## 핵심 구현

| 문제 | 구현 및 코드 샘플 |
| --- | --- |
| 참가자만 입력 반응이 늦음 | 참가자 화면에는 기본 공격 준비 자세를 즉시 표시하고, 참가자 본인의 위치 보간 설정을 40ms로 조정했습니다. 실제 공격과 피해는 서버에서 판정합니다. [협동 입력 반응](01-coop-input.md) |
| 마지막 예고와 실제 발사 방향이 어긋날 수 있음 | 준비 종료 0.12초 전에 발사점과 방향을 확정하고, 최종 예고와 실제 발사에 같은 데이터를 사용합니다. [보스 투사체 예고](02-boss-telegraph.md) |
| 참가자 저장 실패로 결과 처리와 귀환이 얽힘 | 수신 확인을 파일 저장과 분리하고, 저장에 실패하면 확정한 스냅샷으로 재시도합니다. 이미 저장된 결과 ID는 중복 기록을 건너뜁니다. [전투 결과 저장](03-battle-result-save.md) |

방 생성과 참가는 Unity Authentication·Lobby·Relay로 연결했습니다. Google Sheets 원격 데이터 로딩에 실패하면 로컬 캐시와 내장 기본값으로 복구합니다. 퀘스트 개발 도구에서는 보상 저장 실패를 재현하여 상태와 저장 파일을 비교할 수 있도록 했습니다.

## 검증 기록

실제 Unity 보스 FSM과 Animator 이벤트로 생성한 투사체 5발의 방향이 마지막 예고와 일치했습니다. 별도 로컬 호스트·클라이언트 검사에서는 중간 예고가 전송 간격 때문에 생략돼도 최종 발사점과 방향이 참가자에게 전달되는지 확인했습니다. [검증 조건과 결과](02-boss-telegraph.md)

## Unity 데모 실행

1. 저장소를 내려받은 뒤 Unity Hub에서 `UnityDemo` 폴더를 추가합니다.
2. Unity **6000.4.8f1**에서 `Assets/Scenes/PortfolioDemo.unity`를 열고 **Play**를 누릅니다.
3. **Start boss attack**을 누릅니다. 분홍 예고가 위치를 추적하다가 금색으로 바뀌면 공격 경로가 확정됩니다. **Lane** 버튼으로 경로를 벗어나 피할 수 있습니다.

데모 화면은 Unity 기본 GUI로 구성했습니다. 외부 에셋 구매나 서비스 계정 없이 실행할 수 있습니다.

코드 문서는 원본 C# 발췌입니다. 데모는 보스 예고·경로 확정·회피 흐름을 독립적으로 확인할 수 있게 구성했습니다.
